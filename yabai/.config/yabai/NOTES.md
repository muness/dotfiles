# Window manager notes

## TrellisWM (tried 2026-10-14) — no

Tried [TrellisWM](https://trelliswm.app) as a yabai replacement. The fractal
nest/zoom idea is neat; the empty gaps kill it.

Docking windows to screen edges always leaves a **Desktop** leaf in the split
("The Desktop stays between"). On an ultrawide that is a fat teal hole between
apps. There is no UI to turn that off. Packed tiling only happens if you dock
onto another *window's* edge, or by hand-editing arrangement JSON — which Trellis
happily undoes.

Also tried collapsing that Desktop node and setting `gap` to 0. Still not a
product I want to fight every day. Uninstalled. Sticking with yabai/skhd/borders
until something else does real full-tile without the circus.
